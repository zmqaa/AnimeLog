## 第一轮

1.0.4+5 开始使用统一的浅色背景、青绿色强调色、圆角卡片与输入框。第一轮覆盖动漫库、本机设置入口、AI 录入、个人记录表单与详情页。

- 动漫库根据可用宽度排成一至三列，展示封面、状态、评分、标签、集数和进度条。没有封面时显示确定性的渐变占位，不虚构作品封面。未知总集数仍显示 `?`，进度条为零，不使用持续加载动画。
- 搜索和状态筛选显示真实数量；清空搜索有独立按钮，切换到本机页再返回会保留搜索文字。窄屏添加按钮使用带文字提示的加号，宽屏使用完整按钮。
- 宽度达到 840 时显示桌面侧栏，否则使用底部导航。主内容和侧栏均可滚动，卡片由内容决定高度，不用固定高度网格裁切大字体。
- 详情页展示封面与观看进度，把总体备注放在前面；作品资料和观看日期可展开。增加直接进度 +1 与撤销，复用已有事务和回执规则。分集备注、观看历史及资料补全保留原操作。
- 表单分为作品身份、观看记录、评价与感想，其他作品资料可以展开。保存按钮固定在键盘上方；草稿恢复、返回确认及 Ctrl+Enter 保留。
- AI 录入区分查找和资料确认步骤，真实候选及已选择状态均可见，仍需确认后进入表单再保存。

Android 和 Windows 共用页面、控制器、应用用例和数据库规则，同一功能没有平台开关。手机与桌面的差异来自可用宽度；数据分别存于本机，JSON 备份用于迁移，不自动同步。原生文件选择器、安全存储、输入法和返回键仍需 Android 设备验证，桌面通过不能代替这些检查。

## 检查与预览

`test/responsive_ui_test.dart` 使用独立内存 SQLite 和虚构作品，检查桌面/手机导航、搜索/筛选、评分零、详情进度与撤销、390×600 与 1.8 倍字体、844×390 的矮窗口，以及手机键盘遮挡下的保存。实时 Flutter 测试明确调用 `setSurfaceSize` 设置实际布局尺寸；旧的窄屏测试也已同步修正。

可选预览命令（本机 Windows 字体路径）：

~~~powershell
& 'D:\dev\flutter\bin\flutter.bat' test test/responsive_ui_test.dart --no-pub -j 1 --reporter expanded --dart-define=UI_PREVIEW=true
~~~

生成 `build/ui_preview/library-desktop.png`、`library-phone.png`、`detail-desktop.png` 和 `editor-desktop.png`。预览加载 Windows 微软雅黑和 SDK MaterialIcons，避免测试默认 Ahem 方块字体；默认回归不依赖这些字体路径。这些图片由真实 Flutter 页面渲染，展示专用测试记录，不读取正式库、Key 或远程封面，不是 Android 真机截图。

第二轮已细化设置、备份、资料补全说明、日期选择，并增加本地统计。后续继续实际设备体验检查与细节调整；图谱、漫画仍留到后续版本。

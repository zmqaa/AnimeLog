# AnimeLog 开发验收清单

以下是待完成工程的验收条件，不是已通过报告。每个阶段只报告实际执行结果；核心独立检查不证明 SQLite 事务或真机插件可用。

2026-10-10 的逐项范围和检查见 [实现状态](IMPLEMENTATION_STATUS.md)。离线闭环、SQLite 事务、JSON/v5 迁移及 v1→v2 升级测试已通过，Windows 原生备份页面流程通过。现已实现 AI 录入、候选确认、取消与超时、封面缓存，Windows 安全存储及本机 HTTP fixture 原生新建流程已通过，Bangumi 公开源已实际查询成功。真实模型联调、系统选择器人工操作、Android 真机 / 安全存储和正式包验收尚未完成，下方清单不整体标记通过。

现已补齐分集备注的新增 / 编辑 / 删除、进度降低时的可选批量历史清理，以及独立资料补全。Windows 原生页面测试覆盖确认前不写入、取消保留数据、同事务清理历史、真实 HTTP 资料预览及仅填空缺字段。用户已反馈实际 AI 录入正常；更多作品形式和异常场景仍需样本验收。

## A. 工程与平台验证

- Android 和 Windows 都能构建并运行同一工程，固定正式 applicationId。
- SQLite 创建、关闭、重开后数据仍在；明确 schema 迁移能保留旧数据。
- 安全存储写入 / 读取 Key 可用；Key 不进入普通数据库或日志。
- 两端能使用原生文件选择器读入和导出 UTF-8 JSON，取消无副作用。

## B. 离线记录

- 无 AI 配置、断网状态下可以手动添加、查看和编辑。
- 新记录默认在看、进度 0，没有自动历史或观看日期。
- 同名记录允许独立存在；同一作品已有记录全部看完时，程序建议下一刷，用户仍可覆盖次数或改为普通。
- 同名不同来源、不同季度 / 形式不串刷次；来源不明的标题关联须先确认；已有未完成记录仅提醒。
- 旧标签可以建议下一刷；重复 UUID 或多条无标签记录不抬高刷次；没有一刷记录也可手工加二刷。
- 评分 0、清空评分、清空日期、进度归零和中文备注可保存。
- +1 只新增一个集数事件，事务读到最新进度；写历史失败时进度不变。
- +1 的即时撤销同时恢复进度并删除该次新增事件，后续操作发生或回执失效时不能撤销旧操作。
- 修改进度默认保留历史；显式批量删历史先显示数量并在事务中执行。
- 已知总集数到顶后 +1 禁用，未知总集数不会被猜成 12 或 24。
- 删除记录级联清理其历史和备注。
- 删除前显示关联删除数量；只删除选定 UUID 的数据，不影响同作品的其他刷次。
- 分集备注可新增、修改、确认删除；同集多条备注保留独立 UUID，不影响总体备注、进度或历史。
- 批量清理的过期预览及同数量不同历史被拒绝；删除失败时进度、总体备注和历史一起回滚。
- 已有记录资料补全只填空缺，预览确认后才写入；总集数冲突时保留个人状态和进度，false 完结值保留。

## C. JSON 与旧数据

- 新格式导出 → 完整恢复后内容及关系一致，内部整数 ID 改变不影响关联。
- 同份文件追加两次不增记录、历史或备注。
- 导入不执行新建建议，不重新编号原有重刷标签。
- 不按标题合并普通 / 重刷记录，不覆盖已有 UUID 的个人数据。
- 完整恢复确认展示数量，先创建本机快照，失败整体回滚。
- v5 的总体与分集备注、进度、标签、历史正确迁移。
- 旧文件的整数 ID 与本机碰撞时，历史不关联错作品。
- 不支持类别在预览中列明；Key、本机缓存路径、草稿不进入导出。

## D. AI 只新建

- 名称、第二季、剧场版、OVA 分别得到一条可确认的作品草稿。
- 批量 records 响应被拒绝，不取第一项；多部输入不展开。
- AI 返回 status、progress、score、watchedAt 或重刷标签时，这些字段被隔离。
- AI 只从实际给出的候选 ID 中选取；形式 / 季度冲突不能自动接受。
- 唯一精确匹配可以跳过候选 AI；无匹配和 API 失败保留手动添加路径。
- 同名已有记录不被更新，普通和重刷都调用创建接口。
- 创建不写观看历史，草稿个人字段由表单明确填写。
- 重复点击、保存请求结果丢失后的同 draftId 重试，只产生一条新记录；这是 SQLite 集成测试重点。
- 改变输入后旧网络响应不覆盖新结果，取消后不继续保存。

## E. 交互与正式包

- Android 真机验证返回键、输入法、进后台、草稿恢复、文件导入导出、覆盖升级数据保留。
- Windows 验证键盘、窄窗口、系统文件对话框和中文输入。
- 缓存封面失败不影响保存，联网失败可重试，离线列表与编辑正常。
- 大字体和较长标题不遮挡主要操作；保存时反馈明确。
- 验收正式构建或 release 模式；不能用 debug 启动成功替代安装包验收。

## F. 总览与明暗外观（新增源码，尚未运行验收）

- 浅色／深色切换覆盖主页面、侧栏、详情、录入与弹窗；重开保留选择，JSON 恢复保留本机外观，存储失败保留原主题并允许重试。
- 同名及重刷记录独立计数，累计进度不重复加历史；仅统计已填写的时长，未知集数明确排除；评分 0 有效。
- 趋势按观看日历日期统计，近 7／30 日含今天，今年包含闰日；缺失历史不补造，未来日期不进入截至今天的趋势。
- 新增、编辑、删除与恢复后总览更新，状态入口进入对应筛选，最近记录打开正确 UUID；大字体和窄窗口下图表可滚动且数值可读。
